# Toyamas Cloud Roadmap

The vision and progression phases for Toyamas Cloud.

---

## ✅ Phase 1: MVP Core (Completed)
- Next.js 15 control plane & dark mode developer interface
- PostgreSQL 16 schema & Prisma ORM
- Bcrypt password hashing & JOSE JWT sessions in `httpOnly` cookies
- AES-256-GCM encrypted secrets at rest
- Real system host hardware metrics & zero mock data
- Project management & DNS-safe slug validation
- Dockerode container lifecycle with CPU quota & memory limits
- Git cloning, multi-stage runtime buildpacks (Next.js, Node.js, Python, Laravel, Dockerfile)
- Zero-downtime container transition with HTTP health probes
- Dynamic Caddy reverse proxy integration & automatic TLS
- Redis background worker queue & GitHub webhook deployment
- Live container telemetry & process monitor
- Security hardening, rate limiting, and audit trail
- CLI executable tool `toyamas`

---

## 🚀 Phase 2: Enhanced Developer Experience (Next)
- GitHub OAuth application flow & private repository deploy keys
- Custom environment variable groups & shared variables
- Instant rollback to previous deployment commits
- One-click managed databases (PostgreSQL, MySQL, Redis)

---

## 🏢 Phase 3: Team Collaboration & Organizations
- Multi-user RBAC & team permissions
- Fine-grained project member roles (Owner, Maintainer, Viewer)
- Personal API access tokens
- Discord & Slack deployment notifications

---

## 🌐 Phase 4: Multi-Node Clustering & Distributed PaaS
- Distributed agent daemon for multi-VPS orchestration
- Control Plane to Node registration via mTLS
- Geo-distributed edge proxying and container scheduling
